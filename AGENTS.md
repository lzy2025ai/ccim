# ccim

ccim connects a project directory on this Mac to Feishu / Lark or WeChat, so the user can chat with Claude Code or
Codex in that project from their phone.

- **To set it up for the user** (connect a project to Feishu or WeChat, add projects or WeChat accounts, fix a bot
  that doesn't reply): follow [skills/ccim-setup/SKILL.md](skills/ccim-setup/SKILL.md).
- **To move the current Claude Code conversation to the phone and back**: follow
  [skills/feishu-handoff/SKILL.md](skills/feishu-handoff/SKILL.md).
- **To change ccim's own code**: read [CLAUDE.md](CLAUDE.md) first (structure, design decisions, how to test without
  Feishu, the release workflow).

User-facing docs: [README.md](README.md) (中文) · [README.en.md](README.en.md).
