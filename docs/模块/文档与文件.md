# 文档预览、文件传输、设备管理

改 docs.py、filesend.py、devices.py，或网页的文档面板、公众号排版前先读。

- 文档预览（#34，`ccim/docs.py`）：对话里的 .md / .html / .docx / .pdf（Agent 发的、用户上传的）点开在右侧面板（手机全屏，`DOC`、`drawDoc`）。
  Agent 每发一次存副本（日志目录 snaps/<对话>/，记录里的 snap），面板切版本；最新的一版读原文件。文档里相对路径引用的图片
  （HTML 还有样式表、脚本）由 `docs.view` 打包成 data: 地址，所以别的电脑、服务器上也能显示，HTML 放 sandbox iframe 的 srcdoc。
  替换要避开 `<script>` 里的代码（#248）：`getDataURL(t)` 会被当成 CSS 的 `url(t)` 改坏整段脚本；`url()` 也只在找到本地文件时才改。
  Markdown 用 `docMd`（比聊天的 md() 全，每块带 data-l 原文行号）。保存（/api/doc/save）带打开时的 mtime，文件被改过就拒绝；
  记一条 type=edit，对话 meta 的 doc_edits 在下一次发消息时拼在前面告诉助手。Word 自己转（`docx_html`），只能看。PDF（#311）后台不读内容，iframe 直接指向文件地址，交给浏览器自带的阅读器（按需分段取，大文件不用等整个下完）。服务器总控回文件一律不许被嵌（X-Frame-Options: DENY，#16 起就是统一的加固），PDF 放宽到只许本站嵌（`filesend.framing`），能跑脚本的类型不放宽；iPhone 上嵌着的 PDF 可能只显示第一页，顶上给「在新标签页打开」（主屏幕图标打开的网页新标签页没登录，不给）。
- 工作区（#206，`ccim/workspace.py`，原型 docs/prototype/workspace.html）：对话页头部「对话 | 工作区」切换（每个对话记在 localStorage，`WS`）。
  工作区 = 左边对话工作目录（`Platform.chat_dir`，和 `_bridge` 一样算）的文件树、中间编辑区、右边还是这个对话；手机上是头部「文件」→ 全屏文件树 → 全屏文件，「问 AI」回对话。
  编辑区就是文档面板画在中间（DOC.ws，每个标签一个 DOC，`drawWsDoc`），自己改的停 1.2 秒自动保存，连着几次保存在记录里合成一条 edit（MERGED 带 edit、同一个 id）。
  docs 多了 text 类型（代码、纯文本，直接改）；工作目录里的文件 `ws_in` 放行预览、下载。文件操作 /api/ws/*（`resolve` / `entry_path` 圈在工作目录里，软链接指到外面的不列；删除进废纸篓，返回撤销用的记号）。
  AI 改了哪些文件：Turn.writing / changed / created（编辑工具，进度里实时推，网页标「正在写」）+ 答完时扫目录里修改时间晚于这一轮开始的（`changed_since`，主目录不扫），
  记在回答的 changed（用户自己在网页里保存的不算，`user_saved`），回答下面列出来、点了在工作区打开。发消息带 ctx.ws_file（正在看的文件）拼在前面。
  切换动效用 View Transitions（html[data-vt]），不支持或减弱动态效果时直接切
- 回复里的路径（#296，`fpLooks` / `fpScan` / `fpMenu`）：聊天 md() 把反引号里像路径的（带 / 或有扩展名，命令、网址不算，行号去掉）标成 code.fp，
  渲染后一次性问 /api/ws/paths（`workspace.paths`，圈在工作目录里、存在的才返回，按 电脑|对话|路径 缓存在 FP），对上的才能点。
  菜单：打开（openDoc）、在访达中显示（/api/ws/reveal = `open -R`，只在网页就开在这台电脑上时出现；别的电脑转来的、服务器上的都拒绝）、下载。
  文件夹只有「在访达中显示」，所以别的电脑上文件夹不给点。只管主对话和侧边对话里的回复
- `ccim/filesend.py`：对话里的文件发给浏览器（#76）。本机的边读边发，支持 Range（206 / 416）和 ETag（304）。别的电脑上的（网页的 /api/file 带 machine，平台 `_remote` 和服务器 hubserver 都走 `serve_peer`）按段取 /api/file/part（一段 4 MB，回应是一行 JSON 文件信息 + 这一段），经现有转交通道（签名照旧），收到一段写一段、预取两段，所以没有大小上限；中途文件被改（ETag 变了）就断开连接。那边是旧版本（part 返回 404）时退回整个文件转发。链接、<img>、<video> 带不了 X-CCIM 头，所以 /api/file 在 `_remote` 里只校验 Host
  Content-Disposition：图片、视频、音频、文本、PDF 回 inline，其余（zip、exe 等）回 attachment，iPad 的 Safari 遇到 inline 的 zip 会说下载不了。对话里的文件不开新窗口：从主屏幕图标打开的网页（standalone），新窗口和它不共用 Cookie，是没登录的。standalone 下本来也下载不了文件，所以点文件先 fetch 下来，再用 navigator.share({files}) 交给分享面板；取完离点击太久分享会被拒（NotAllowedError），就留着等用户再点一下。
- 公众号排版（#35）：Markdown 文档的面板多一个「公众号」视图（`wxView`）。`wxHtml` 把 `docMd` 的结果套上主题的内联样式
  （公众号编辑器去掉 class 和样式表，只认内联的；`WX_THEMES` / `wxCss`，主题记在 localStorage），外链改成文末参考资料，代码块的空格换行换成 &nbsp; / <br>。
  复制（`wxCopy`）去掉 data-*、class 后以 text/html 写剪贴板，图片是 data: 地址；每张图下面有复制图片（画到画布转 PNG）、下载。
  在排好版的页面上直接改（`blockClick`）：段落、标题、引用、列表用 contenteditable，失焦时 `blockMd` 转回 Markdown 换掉 data-l 那几行；
  表格、代码、图片弹原文小框。显示没变化的不算改（比较 docMd 结果）
- `ccim/devices.py`：设备管理（#100）。「设置 → 电脑」点一台进入 #/settings/machines/<编号>/<概况 | files | clean>，接口 /api/fs/*，
  按 X-Machine 转到那台电脑。范围是那台的主目录（realpath 后比较）；主目录本身、第一层的系统文件夹（KEEP）和 ~/.ccim 不能删、不能改名
  （网页上传留下的 uploads 除外）；删除 = 移到 ~/.Trash。预览、下载走 /api/file 和 /api/doc，chat 传 "@fs"（FS_CHAT），
  `_file_ok` / `doc_versions` 按设备范围放行，只认本网页发起的请求（Sec-Fetch-Site）。磁盘清理 `Cleaner`：后台线程扫描（缓存、很久没动的项目依赖、
  大文件、下载文件夹旧文件、废纸篓、旧上传），结果存 scan.json，清理只认结果里的路径；缓存和废纸篓清空内容，其余移到废纸篓。
  系统权限（#266）：`perms()` 查屏幕录制、辅助功能、完全磁盘访问，进 state（电脑列表标「缺…权限」）和概况页；Agent 跑的命令算在后台的 Python 头上，
  所以用这个 Python 起子进程查（每次是新进程，刚授权完就能查到，30 秒缓存）。完全磁盘访问靠能不能读 TCC.db 判断，关了 SIP 的电脑上总是「已开启」。
  缺权限时 `perm_note()` 拼进 Claude / Codex 的系统提示：没授权时截屏只拿到壁纸、不报错，要 Agent 主动告诉用户。
  操作记在 ops.jsonl，概况页列最近的。「让 Agent 处理」打开新对话（工作目录是这个文件夹）或某个 Agent 的新对话，要处理的路径先写进输入框（prefill / draftText）
